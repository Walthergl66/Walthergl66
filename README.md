## Proyectos destacados

### MeetFlow
**Gestión de reuniones y trabajo en equipo.** Agenda, tareas, decisiones, permisos por rol y actualizaciones en tiempo real.

- **Tecnologías:** NestJS, Next.js, Prisma, PostgreSQL, WebSockets
- **Lo más destacado:** autenticación JWT con refresh tokens, control de acceso por roles, auditoría y búsqueda de texto en PostgreSQL.
- [Ver código y documentación](https://github.com/Walthergl66/meeting-management-system)

### Restaurant Management System
**Sistema de gestión para restaurantes.** Productos, mesas, pedidos, cocina, caja y aplicaciones web y móvil.

- **Tecnologías:** Java, Spring Boot, PostgreSQL, Next.js, Expo
- **Lo más destacado:** backend modular, migraciones con Flyway y pruebas con JUnit y Testcontainers.
- [Ver código y documentación](https://github.com/Walthergl66/restaurant-management-system)

### PostgreSQL Backups con Telegram
**Automatización de respaldos.** Bot de Telegram, API REST y panel web instalable para gestionar copias de seguridad.

- **Tecnologías:** Python, FastAPI, React, PostgreSQL, Docker
- **Lo más destacado:** respaldos con `pg_dump`, autenticación JWT y protección de credenciales.
- [Ver código y documentación](https://github.com/Walthergl66/backups-supabase)

### Navira: Escape de Manta Zombie
**Simulación y visualización en tiempo real.** Las rutas se recalculan sobre un grafo vial cuando aparecen obstáculos y amenazas simuladas.

- **Tecnologías:** Python, FastAPI, React, WebSockets, Grafos
- **Lo más destacado:** planificación de rutas, servidor autoritativo y arquitectura limpia.
- **Nota:** es una demo local, no está desplegada en AWS.
- [Ver código y documentación](https://github.com/Walthergl66/SPOOKYTHON)
